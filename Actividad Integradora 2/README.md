# Portafolio Personal - Jonathan Mauricio Rodriguez Moreno

## Descripción

Este proyecto corresponde al desarrollo de un portafolio personal realizado como parte de las actividades académicas de
Programación Web.

El sitio presenta infrmación personal, habilidades, proyectos realizados y un formulario de contacto. Para esta segunda
actividad se incorporaron funcionalidades utilizando JavaScript, manteniendo una estructura organizada mediante archivos
externos de HTML, CSS y JavaScript.

## Nuevas funcionalidades con JavaScript

En esta segunda actividad se incorporó JavaScript al portafolio mediante un archivo externo llamado `script.js`.


## Tecnologías utilizadas

-   HTML5
-   CSS3
-   JavaScript
-   GitHub

## Estructura del proyecto

```text
PORTAFOLIO/
│
├── index.html
├── sobre mi.html
├── habilidades.html
├── proyectos.html
├── contacto.html
│
├── css/
│   └── styles.css
│
├── js/
│   └── script.js
│
└── img/
    └── imágenes del proyecto
```

## Instrucciones para ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Verificar que se mantenga la estructura de carpetas.
4. Abrir el archivo `index.html`.
5. Ejecutar el proyecto en un navegador web.
6. Utilizar el menú de navegación para acceder a las diferentes secciones del portafolio.
