Actividad Integradora 2

Esta actividad está realizada acorde a las especificaciones con fecha de entrega 30/08/2026.

Título del proyecto:

Desarrollo de un portafolio personal interactivo utilizando HTML, CSS, JavaScript y GitHub

Descripción:

Cada estudiante deberá actualizar el portafolio personal desarrollado en la Actividad Integradora 1, incorporando nuevas funcionalidades utilizando JavaScript. El objetivo es aplicar los conocimientos adquiridos durante las clases para crear un sitio web más dinámico e interactivo, manteniendo una estructura organizada y un adecuado control de versiones mediante GitHub. El proyecto deberá desarrollarse de forma individual y evidenciar el progreso mediante varios commits.
