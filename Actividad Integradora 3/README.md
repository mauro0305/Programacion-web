# TechControl

## Sistema de control e inventario de equipos tecnológicos

TechControl es una aplicación web desarrollada como parte de la Actividad Integradora 2. Su objetivo es permitir el registro y consulta de equipos tecnológicos mediante una aplicación desarrollada con PHP, MySQL, HTML, CSS y JavaScript.

El proyecto implementa una estructura básica del patrón MVC (Modelo-Vista-Controlador), permitiendo separar la conexión a la base de datos, la lógica de los registros, el procesamiento de las solicitudes y la presentación de la información.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- PHP 8.2
- MySQL
- XAMPP
- Apache
- phpMyAdmin

---

## Funcionalidades

La aplicación permite:

- Registrar equipos tecnológicos.
- Validar los datos del formulario mediante JavaScript.
- Verificar campos obligatorios.
- Validar la longitud de determinados campos.
- Validar valores permitidos para el estado del equipo.
- Registrar la información en una base de datos MySQL.
- Consultar los equipos almacenados.
- Mostrar los registros mediante una tabla HTML.
- Utilizar una estructura organizada basada en MVC.
- Mantener separados el modelo, controlador y las vistas.


Para el entorno local se utiliza:

Servidor: localhost
Usuario: root
Contraseña: sin contraseña
Base de datos: techcontrol



Ejecución del proyecto

Para ejecutar el proyecto de manera local:

Instalar XAMPP.
Iniciar los servicios Apache y MySQL.
Colocar la carpeta del proyecto dentro de:
C:\xampp\htdocs\
Crear la base de datos techcontrol mediante phpMyAdmin.
Crear la tabla equipos con los campos correspondientes.
Abrir el proyecto desde el navegador utilizando ruta
