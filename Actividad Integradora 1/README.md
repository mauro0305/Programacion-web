# Actividad Integradora

## Jonathan Rodriguez

Nombre del proyecto: Portafolio en GitHub

Descripción del proyecto

Este proyecto consiste en la creación de un portafolio web personal como parte de la Actividad Integradora. El sitio presenta información organizada en diferentes secciones e incluye un formulario de contacto y un pie de página con información del estudiante y enlaces relevantes.

Tecnologías utilizadas

- HTML5
- CSS3

Instrucciones para visualizar el proyecto

1. Descarga este repositorio.
2. Abre la carpeta del proyecto.
3. Busca el archivo `index.html`.
4. Haz doble clic sobre el archivo `index.html` para abrirlo en tu navegador web.
