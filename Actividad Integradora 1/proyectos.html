Actividad Integradora 1:

Esta actividad esta realizada acorde las especificaciones con fecha de entrega 23/08/2026

TITULO DEL PROYECTO: Desarrollo de un portafolio personal utilizando HTML, CSS y GitHub.

Descripción de la actividad Cada estudiante deberá desarrollar un sitio web que funcione como su portafolio personal. El sitio deberá presentar información básica del estudiante, sus habilidades, proyectos o trabajos realizados y una sección de contacto. El proyecto deberá ser desarrollado con HTML y CSS y almacenado en un repositorio público de GitHub. No se aceptará únicamente la carga final del proyecto. El estudiante deberá realizar varios commits que permitan observar el progreso del trabajo.
